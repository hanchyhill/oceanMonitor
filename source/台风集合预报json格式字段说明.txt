【索引5】风圈数据 windRadiusInfo（与程序 calRadius.js、cyclone-ens.vue 一致）
整体结构：长度为 3 的数组，依次对应三种风速阈值下的不对称风圈；仅部分机构/模式提供，前端通过 model 配置 containWindRadius 控制是否绘制。

[
  [18, r1, r2, r3, r4],   // 8级风圈：风速阈值 >18 m/s
  [26, r1, r2, r3, r4],   // 10级风圈：>26 m/s
  [33, r1, r2, r3, r4],   // 12级风圈：>33 m/s
]

每个子数组（单行风圈）共 5 个元素：
  索引0：该档的风速阈值（米/秒），数值为 18 / 26 / 33，与档位对应。
  索引1～4：以台风中心为原点、按经纬方向划分的四个象限的风圈半径，单位：米（m）。
    象限划分（相对中心点 [经度, 纬度]）：
      索引1：经度≥中心 且 纬度≥中心（东北侧）
      索引2：经度≥中心 且 纬度＜中心（东南侧）
      索引3：经度＜中心 且 纬度＜中心（西南侧）
      索引4：经度＜中心 且 纬度≥中心（西北侧）
    半径为 0 表示该象限该时效无此档风圈或数据缺失。
    确定性预报风圈绘制时，若某档四个象限均为 0 或均为 100，则视为该档无有效数据（占位 100 视为空）。

风圈概率（集合）：src/libs/calRadius.js 中 getHitCount 使用 track 每点索引5，按风速档 windR 取 windIndex——18→0、26→1、33→2；对格点判断是否在对应象限半径内（球面距离与半径比较），再对集合成员比例做等值线。网格分辨率约 0.25°。

确定性预报风圈（地图 SVG）：仅使用 detTrack.track 各点的索引5，将每档 slice(1) 得到四象限半径数组，经 createWindRadiusPolygon 拼成四分圆闭合多边形；可按 radiusTimeInterval（小时）筛选显示的时效点。
